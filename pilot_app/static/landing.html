我们只做三件事

把「我记得要回」变成「已完成」

读信、写摘要、发回给你。不帮你回信，不把数据给第三方，不用你的邮件训练模型。

授权 · 只读

只读令牌

用的是邮箱的授权码（不是登录密码），全程只读：不标记已读、不移动、不删除。 你可以随时在邮箱后台撤销它，撤销后我们立刻读不到。

留存 · 正文

正文不留存

报告发出后，我们这边不留邮件正文；跳过邮件的正文根本不入库。 留下来的只有元数据与你自己标记的待办状态。

训练 · 零

不用于训练

不用你的邮件训练模型，不卖也不共享给广告方，也没有任何遥测。 生成报告时正文会发给模型服务商——这一条写在下方的披露框里，不藏着。

隐私说明

我们会对你的邮箱做什么？

简要说明：程序只读取新邮件，不会修改邮箱状态或删除邮件。

✅ 安全底线

  • 只读收信：不会标记已读、移动或删除任何邮件。
  • 仅处理本校邮件：只处理本校邮箱发来的邮件；其他邮件不进入报告处理流程，仅记录一行“已跳过”和发件人。
  • 不保留正文：报告生成并发送后，服务器不保留邮件正文。
  • 凭据加密保存：邮箱授权码和 API key 加密存储，每个账号的凭据相互隔离；修改邮箱密码后，其他设备上的登录会立即失效。详见《隐私政策》。
  • 无行为追踪：不统计使用行为，不包含遥测，不使用你的邮件训练模型，也不向广告商出售或共享数据。
  • 处理可追溯：跳过的邮件不会被静默丢弃，每一封都会记录在运行日报中。

⚠️ 使用前须知

数据外传
生成报告时，邮件正文会通过加密连接发送给大模型服务商，如 DeepSeek、OpenAI、火山方舟。 内测期间默认使用管理员的 API key，因此调用记录会归属管理员账号；切换为你自己的 key 后， 记录仅归属你。联网核实时，系统还会从邮件主题提取检索词并发送给搜索服务商，如豆包； 使用管理员搜索 key 时，查询记录同样归属管理员账号。服务商受其自身隐私政策约束， 我们无法保证其不将数据用于训练。请勿用它处理你无法接受外传的内容。

模型误差

报告由模型生成，可能遗漏、误解或编造信息，不代表学校官方通知。涉及选课、缴费、报名、签证、毕业等有实际后果的事项， 请自行核对原始邮件，一切以原邮件为准。

自行部署

如不希望邮件经过第三方服务器，可自行部署。部署后，邮件只经过你自己的服务器。 仓库与 AGPL-3.0 许可证：GitHub 仓库。如不便自行部署，可申请内测名额。

常见问题

开始之前，你可能想问这些。

目前只开放 CityU 校园邮箱。

Q1

会读到我其他的邮件吗？

只会读到你从城大邮箱转发过来的信——转发规则是你自己设的，可以随时关掉。 不是本校发来的邮件只记一行「已跳过」和发件人，正文不入库。

Q2

会用我的邮件训练模型吗？

不会。不训练、不人工逐封阅读、不卖给第三方，也没有遥测。 但要说清一件事：生成报告时正文会发给模型服务商（谁、发什么，见上面的披露框）。

Q3

要收费吗？

目前免费，默认用管理员提供的模型 key，你不花钱；也可以换成自己的 key， 费用与调用记录就都在你自己的服务商账号下。

Q4

我的邮箱能用吗？

QQ / 163 / 126 / Gmail / iCloud / Yahoo 这些都可以（要在邮箱设置里开启「收发邮件服务」并生成授权码）。 微软系（Outlook / Hotmail / Live）用不了——微软已停用授权码登录，这不是我们能改的。

Q5

报告会不会出错？

会。它由模型生成，可能漏掉、误解或凭空写出内容，报告不是学校的官方通知。 涉及选课、缴费、报名、签证、毕业的事，请以原邮件为准。

Q6

不想用了怎么办？

在「邮箱设置」里停用邮箱，或者删除账号；删除后邮件正文与报告一并清掉。 也可以只把城大邮箱里那条转发规则关掉——我们这边就再也收不到信了。

它本身是一个网页，所以「安装」跟装普通 App 不一样。 安卓可以下载安装包，也可以直接让浏览器装；iPhone 只能用 Safari 装到主屏幕。 iOS 不允许安装 App Store 以外的应用，这是苹果的限制，不是我们没做。

下面的图是示意图：颜色和位置可能跟你的手机略有差别， 作用是标出该点哪一个按钮。找不到时对着文字描述看。

安卓 · 方法一：下载安装包 功能最全

{{APK_BUTTON}}
  1. 下载：用手机上的浏览器打开这一页，点上面的下载按钮。文件会存进「下载」文件夹。
  2. 允许安装：点开刚下载的文件。系统会先拦一下，说不能安装未知来源的应用—— 点「设置」，找到你刚才用的那个浏览器，打开它的「允许安装未知应用」， 然后返回再点一次。
  3. 仍然安装：装的时候可能还会提示「Play 保护机制」或「未经检测的应用」。 这个安装包没有上架 Google Play，所以这类提示是正常的，选「仍然安装」就行。
  4. 以后更新：装好后桌面上会出现图标。以后有新版本，回到这一页重新下载、直接覆盖安装即可， 账号和数据都不会丢。

安卓 · 方法二：用浏览器直接装 最省事

不下载任何文件，也看不到「未知来源」的提示。

  1. 打开：用 Chrome 打开这一页。
  2. 安装：点右上角「⋮」，选「安装应用」；没有这一项就选「添加到主屏幕」。
  3. 确认：确认之后，桌面上就有图标了。

iPhone / iPad

iOS 装不了安装包，只能「添加到主屏幕」。加完之后是一个独立图标， 打开看不到地址栏，用起来和下载的 App 一样。

  1. 换到 Safari：必须用 Safari。在微信、QQ、Chrome 里都加不了。 先把这一页的网址复制下来，粘到 Safari 的地址栏里打开。
  2. 点分享：点屏幕最底下中间那个「分享」按钮——一个方框、里面一个向上的箭头。 如果在最底下找不到，就在页面顶部找。
  3. 添加到主屏幕：在弹出的菜单里往上滑，找到「添加到主屏幕」，点它。
  4. 添加：右上角点「添加」。回到桌面，就能看到新图标了。

怎么确认是真的装好了

从桌面图标打开时，看不到浏览器的地址栏，那才算装好了。 如果顶上还压着一条地址栏，说明打开的仍然是个网页，回到上面重做一次。
