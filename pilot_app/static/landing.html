它是怎么工作的

你在 CityU 的 Outlook 里设一条转发规则，把来信转到你的私人邮箱。学校系统里不需要装任何东西， 我们也不会拿到你的学校密码。然后填一次私人邮箱和授权码，授权码用 AES-256-GCM 加密后按用户隔离存放。

它读你转过来的信，判断是不是本校发来的，把当天要办的事写成一条清单发到你的私人邮箱。 办完的条目点一下收起，它不会被删掉，想找随时能找回来。内测期间默认用管理员提供的模型 key， 你不花钱；想换成自己的 key 也可以，费用和调用记录就都在你自己的服务商账号下。

手机上可以装成一个应用，打开就是同一个清单，课间看一眼就够，不用开电脑。 安卓和 iPhone 的装法在下面那节里一步一步写了。

装到手机上

它本身是一个网页，所以「安装」跟装普通 App 不一样。 安卓可以下载安装包，也可以直接让浏览器装；iPhone 只能用 Safari 装到主屏幕。 iOS 不允许安装 App Store 以外的应用，这是苹果的限制，不是我们没做。

安卓 · 方法一：下载安装包

{{APK_BUTTON}}
  1. 用手机上的浏览器打开这一页，点上面的下载按钮。文件会存进「下载」文件夹。
  2. 点开刚下载的文件。系统会先拦一下，说不能安装未知来源的应用—— 点「设置」，找到你刚才用的那个浏览器，打开它的「允许安装未知应用」， 然后返回再点一次。
  3. 装的时候可能还会提示「Play 保护机制」或「未经检测的应用」。 这个安装包没有上架 Google Play，所以这类提示是正常的，选「仍然安装」就行。
  4. 装好后桌面上会出现图标。以后有新版本，回到这一页重新下载、直接覆盖安装即可， 账号和数据都不会丢。

安卓 · 方法二：不下载安装包

如果不想看到「未知来源」的提示，用这条更省事。

  1. 用 Chrome 打开这一页。
  2. 点右上角「⋮」，选「安装应用」；没有这一项就选「添加到主屏幕」。
  3. 确认之后，桌面上就有图标了。

iPhone / iPad

iOS 装不了安装包，只能「添加到主屏幕」。加完之后是一个独立图标， 打开看不到地址栏，用起来和下载的 App 一样。

  1. 必须用 Safari。在微信、QQ、Chrome 里都加不了。 先把这一页的网址复制下来，粘到 Safari 的地址栏里打开。
  2. 点屏幕最底下中间那个「分享」按钮——一个方框、里面一个向上的箭头。 如果在最底下找不到，就在页面顶部找。
  3. 在弹出的菜单里往上滑，找到「添加到主屏幕」，点它。
  4. 右上角点「添加」。回到桌面，就能看到新图标了。

怎么确认是真的装好了

从桌面图标打开时，看不到浏览器的地址栏，那才算装好了。 如果顶上还压着一条地址栏，说明打开的仍然是个网页，回到上面重做一次。

我们对你的邮箱做什么

下面写的是程序的实际行为，不是法律措辞。

  • 只读收信（IMAP BODY.PEEK[]），不标记已读、不移动、不删除
  • 只处理本校发件域的来信，其余只记一行「已跳过」和发件人
  • 报告发出后，数据库里的邮件正文立即清空
  • 授权码与 API key 加密保存，改密码会吊销全部会话
  • 不向你或任何第三方上报使用情况，没有任何遥测
  • 不用你的邮件训练模型，不卖、不共享给广告方
  • 不静默丢弃邮件，跳过的每一封都会在日报里出现
你需要知道的一件事 生成报告时，邮件正文会通过加密连接发送给大模型服务商（如 DeepSeek、OpenAI、火山方舟）。 内测期间默认用管理员的 API key，所以这些调用记录会落在管理员的模型账号里； 换成你自己的 key 之后，记录就只在你自己名下。开启联网核实时还会从邮件主题提取检索词发给搜索服务商（豆包）， 用管理员的搜索 key 时这些查询记录同样落在管理员账号下。服务商受它自己的隐私政策约束， 我们无法替你保证它不用于训练。请不要用它处理你无法接受外传的内容。

报告由模型生成，会出错

它可能漏掉、误解或凭空写出内容。报告不是学校的官方通知。涉及选课、缴费、报名、签证、毕业 这些有后果的事，请自己打开原始邮件核对，一切以原邮件为准。

也可以自己部署

不想把邮件交给别人的机器，就自己装一份，那样邮件只经过你自己的服务器 （仓库和许可证见上面那节）。不想自己弄就申请这里的内测名额。
