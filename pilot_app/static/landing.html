它是怎么工作的

你在 CityU 的 Outlook 里设一条转发规则，把来信转到你的私人邮箱。学校系统里不需要装任何东西， 我们也不会拿到你的学校密码。然后填一次私人邮箱和授权码；授权码加密保存， 每个账号的密文互相隔离（加密算法与细节写在《隐私政策》里）。

它读你转过来的信，判断是不是本校发来的，把当天要办的事写成一条清单发到你的私人邮箱。 办完的条目点一下收起，它不会被删掉，想找随时能找回来。内测期间默认用管理员提供的模型 key， 你不花钱；想换成自己的 key 也可以，费用和调用记录就都在你自己的服务商账号下。

我们对你的邮箱做什么

下面写的是程序的实际行为，不是法律措辞。

  • 只读收信，不标记已读、不移动、不删除
  • 只处理本校邮箱发来的邮件，其余只记一行「已跳过」和发件人
  • 报告发出后，我们这边不留邮件正文
  • 邮箱授权码和 API key 加密保存；改密码后，其它设备上的登录会立刻失效
  • 不统计你的使用行为，也没有任何遥测
  • 不用你的邮件训练模型，不卖也不共享给广告方
  • 跳过的邮件不会悄悄消失，每一封都会写在日报里
你需要知道的一件事 生成报告时，邮件正文会通过加密连接发送给大模型服务商（如 DeepSeek、OpenAI、火山方舟）。 内测期间默认用管理员的 API key，所以这些调用记录会落在管理员的模型账号里； 换成你自己的 key 之后，记录就只在你自己名下。开启联网核实时还会从邮件主题提取检索词发给搜索服务商（豆包）， 用管理员的搜索 key 时这些查询记录同样落在管理员账号下。服务商受它自己的隐私政策约束， 我们无法替你保证它不用于训练。请不要用它处理你无法接受外传的内容。

报告由模型生成，会出错

它可能漏掉、误解或凭空写出内容。报告不是学校的官方通知。涉及选课、缴费、报名、签证、毕业 这些有后果的事，请自己打开原始邮件核对，一切以原邮件为准。

也可以自己部署

不想把邮件交给别人的机器，就自己装一份，那样邮件只经过你自己的服务器 （仓库和许可证见上面那节）。不想自己弄就申请这里的内测名额。

申请内测名额

这个工具要有一台一直开着的服务器替你读信、写信，所以光下载、装到手机上还用不了—— 内测采取邀请制，我在这台服务器上给你开一个名额，你收到邀请码才算拿到。

留一个邮箱，我人工看过之后把邀请码发给你。

申请之后：我人工看一遍（确认是 CityU 的同学）→ 邀请码发到你留的邮箱 → 注册、配好邮箱，之后每天收到清单。名额换来的是这台服务器上的一个账号： 邮件只经过你自己的设置，报告只发给你。

邀请码由运营者本人的邮箱发出（这里没有系统邮箱）。如果收件箱里没有， 看一眼垃圾邮件，把它标成「不是垃圾邮件」——以后每天的清单就不会再进那里。

还没想好？先看一眼界面——不用账号，数据是编的。

提交即表示你已阅读 《服务条款》 和 《隐私政策》， 并理解上面那条关于「邮件正文会发送给大模型服务商」的说明。

没收到邀请码？

填你申请时留的那个邮箱，我们会在几分钟内再发一次。

只对已经通过的申请有效。要是还没通过，这一下不会发生任何事—— 那表示我还没看到你的申请，或者你的邮箱不在这份名单里。

留言

不用注册也能留言。提交后先只有运营者看到；是否刊登、以什么昵称刊登， 由运营者决定。

  • 刊登时一律匿名，不会出现任何人的邮箱
  • 最多 2 个链接，留言一直保存到你或运营者删掉为止

装到手机上

还没有邀请码？装好之后要用它登录，光装上还进不去。

先申请内测名额

它本身是一个网页，所以「安装」跟装普通 App 不一样。 安卓可以下载安装包，也可以直接让浏览器装；iPhone 只能用 Safari 装到主屏幕。 iOS 不允许安装 App Store 以外的应用，这是苹果的限制，不是我们没做。

下面的图是示意图：颜色和位置可能跟你的手机略有差别， 作用是标出该点哪一个按钮。找不到时对着文字描述看。

安卓 · 方法一：下载安装包 功能最全

{{APK_BUTTON}}
  1. 下载：用手机上的浏览器打开这一页，点上面的下载按钮。文件会存进「下载」文件夹。
  2. 允许安装：点开刚下载的文件。系统会先拦一下，说不能安装未知来源的应用—— 点「设置」，找到你刚才用的那个浏览器，打开它的「允许安装未知应用」， 然后返回再点一次。
  3. 仍然安装：装的时候可能还会提示「Play 保护机制」或「未经检测的应用」。 这个安装包没有上架 Google Play，所以这类提示是正常的，选「仍然安装」就行。
  4. 以后更新：装好后桌面上会出现图标。以后有新版本，回到这一页重新下载、直接覆盖安装即可， 账号和数据都不会丢。

安卓 · 方法二：用浏览器直接装 最省事

不下载任何文件，也看不到「未知来源」的提示。

  1. 打开：用 Chrome 打开这一页。
  2. 安装：点右上角「⋮」，选「安装应用」；没有这一项就选「添加到主屏幕」。
  3. 确认：确认之后，桌面上就有图标了。

iPhone / iPad

iOS 装不了安装包，只能「添加到主屏幕」。加完之后是一个独立图标， 打开看不到地址栏，用起来和下载的 App 一样。

  1. 换到 Safari：必须用 Safari。在微信、QQ、Chrome 里都加不了。 先把这一页的网址复制下来，粘到 Safari 的地址栏里打开。
  2. 点分享：点屏幕最底下中间那个「分享」按钮——一个方框、里面一个向上的箭头。 如果在最底下找不到，就在页面顶部找。
  3. 添加到主屏幕：在弹出的菜单里往上滑，找到「添加到主屏幕」，点它。
  4. 添加：右上角点「添加」。回到桌面，就能看到新图标了。

怎么确认是真的装好了

从桌面图标打开时，看不到浏览器的地址栏，那才算装好了。 如果顶上还压着一条地址栏，说明打开的仍然是个网页，回到上面重做一次。
