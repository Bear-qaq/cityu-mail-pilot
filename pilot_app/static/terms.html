服务条款

版本 1.0 · 生效日期 2026-09-14 · 适用服务：CityU Mail Pilot

一句话：这是一个内测中的免费邮件摘要工具。它帮你把学校邮箱的来信变成一份中文报告， 但它会出错，不是官方通知，随时可能停。用它之前请先读完下面几条。

1. 这是什么服务

CityU Mail Pilot（下称"本服务"）读取你转发到私人邮箱的本校来信，用大模型生成中文摘要报告， 再发回你的邮箱。本服务只读你的邮箱，不回复、不删除、不转发你的邮件给任何人（大模型服务商除外，见 隐私政策 第 3 节）。

2. 关于 AI 生成的报告 —— 请务必理解

报告由大语言模型自动生成，可能遗漏、误解或凭空出错（"幻觉"）。

  • 报告仅供参考，不构成学校或任何机构的官方通知。
  • 一切以原始邮件为准。涉及选课、考试、缴费、报名、签证、毕业、处罚等任何有后果的决定前， 请务必自己打开原始邮件核对。
  • 因依赖报告内容而造成的任何损失，本服务不承担责任。

3. 你的账号与你的责任

  1. 你只能用你自己的邮箱。不要用它处理他人的邮箱。
  2. 你要保管好登录密码、邮箱授权码和 API key。账号下的操作视为你本人的操作。
  3. 内测期间默认使用管理员提供的模型 key，费用由管理员承担，你不必自备 key，也不必付任何费用。管理员可以随时结束内测或调整这一点，届时会提前通知。
  4. 联网搜索同样内置了一把管理员提供的 key：开启联网核实时，从邮件主题提取的检索词会发给搜索服务商，查询记录落在管理员账号下。你可以填自己的搜索 key 覆盖它。
  5. 你也可以改用你自己的 API key（在「AI 模型」里填写）。此后调用费用由你直接付给服务商，调用记录也只在你自己名下。
  6. 用管理员的 key 时，你的邮件正文会经由管理员的模型服务商账号处理；不接受这一点的话，请填自己的 key，或者改为自托管。
  7. 你需要确保自己有权限把邮箱里的邮件内容发送给第三方大模型服务商。若学校或他人对你有保密要求，请先确认清楚。

4. 不可以做的事

以下行为会导致账号被立即停用：

  • 用本服务处理不是你的邮箱，或未经授权获取他人邮件
  • 把本服务用于任何违法用途，或试图用它绕过学校的信息系统规则
  • 故意用超大流量、异常请求或其他方式压垮服务，影响其他用户
  • 试探、扫描、攻击本服务或其服务器，或试图读取其他用户的数据
  • 绕过内测人数上限或邀请机制批量注册

5. 服务是"内测"，没有保证

  • 本服务免费，处于内测阶段，由个人在业余维护。
  • 没有可用性承诺（无 SLA）：可能随时中断、延迟、丢信或出错。
  • 功能可能随时变更或移除。内测人数上限由运营者调整。
  • 我们会努力，但不保证你的报告一定按时送达，也不保证你不会漏掉重要邮件。 请不要把本服务当作你唯一的通知渠道。

6. 如果我们决定停止服务

如果本服务要停止或要清空数据，我们会：

  1. 至少提前 14 天通过你注册的邮箱通知你；
  2. 在通知里给出一段至少 14 天的数据导出窗口，你可以在这段时间里把报告与数据导出带走；
  3. 窗口结束后删除服务器上的用户数据，包含备份。备份按时间滚动保留：服务器上留存最近 14 天，期外副本会自动删除；如果运营者启用了异地备份，同一窗口也会覆盖到异地副本。

你随时可以自己提前导出或删除，不必等我们。

7. 你随时可以离开

在「报告与账户」里可以一键导出或一键删除你的账号。删除后数据不可恢复。 你也可以直接写信给 {{CONTACT_LINK}} 要求删除。

8. 我们也可以停用你的账号

如果你违反第 4 条，或你的使用明显危及服务或其他用户，我们可以在不事先通知的情况下停用你的账号。 在不是紧急情况时，我们会先说明原因。

9. 责任限制

在适用法律允许的最大范围内，本服务按"现状"提供，不对任何间接损失、数据丢失、漏读邮件造成的后果承担责任。 本条不排除法律不允许排除的责任。
